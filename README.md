
# 📡  Freemodbus Slave & Master for Artery AT32F403A

Демонстрационный проект одновременной работы Modbus RTU **Slave** и **Master** на микроконтроллере Artery AT32F403A с использованием разных портов UART.

Проект показывает, как настроить и использовать библиотеку FreeModbus в среде Visual Studio Code + AT32 VSCode IDE (на базе CMake), сконфигурированной через AT32 Work Bench.

# ✨ Особенности проекта

- **Двойная роль:** Микроконтроллер одновременно выступает в роли ведомого (**Slave**) и ведущего (**Master**) устройства Modbus RTU.
- **Разделение интерфейсов:** Slave работает на одном порту UART, Master — на другом.
- **Современный стек:**
   - Среда разработки: **Visual Studio Code** с расширением **AT32 VSCode IDE**.
   - Система сборки: **CMake**.
   - Конфигурация периферии: **AT32 Work Bench V1.2.05**.
- **Библиотека:** Основана на проверенной реализации **FreeModbus**.

# 🛠 Аппаратное обеспечение

Для запуска проекта вам понадобится отладочная плата на базе микроконтроллера **Artery AT32F403A**. Убедитесь, что к разным USART-портам подключены соответствующие шины RS-485 (через преобразователи) или другие устройства Modbus для тестирования.

# ⚙️  Настройка и сборка

## 1. Подготовка окружения
Установите необходимые инструменты:
- [Visual Studio Code](https://code.visualstudio.com/)
- Расширение **AT32 VSCode IDE**: https://www.arterytek.com/download/AT32%20VSCode%20IDE/UM0019_AT32_VSCode_IDE_EN.pdf
- Компилятор ARM GCC (устанавливается вместе с пакетом AT32)
- **CMake** и **Ninja** (или другую систему сборки, поддерживаемую AT32 IDE)

## 2. Генерация кода
  1. Откройте утилиту **AT32 Work Bench V1.2.05**.: https://arterytek.com/file/download/1752
  2. Выберите ваш МК (`AT32F403A`) и плату/конфигурацию пинов.
  3. Активируйте нужные периферийные модули:
     - Два порта USART (для Slave и Master).
     - GPIO для управления выводами DE/RE драйвера RS-485.
     - Таймер.
     - настройте прерывания.
  4. Сгенерируйте код конфигурации в папку вашего проекта.

## 3. Сборка в VS Code:
  1. Клонируйте этот репозиторий.
  2. Скопируйте файлы библиотеки FreeModbus (портированные под AT32) в соответствующую директорию проекта (например, `/modbus`).
  3. Внесите логику инициализации slave и master в сгенерированный шаблон `main.c`.
  4. Откройте папку проекта в VS Code.
  5. Запустите сборку через терминал или интерфейс расширения AT32 VSCode IDE:
  6. Файл прошивки (.hex или .bin) будет находиться в папке `build`.
